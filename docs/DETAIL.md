# 模型连通性测试

在会话头部加一排模型胶囊，随时确认每个中转站 / 模型到底通不通，不用开终端试。

## 功能

- **一键测连通性**：点某个胶囊，宿主代发一次最小请求（`max_tokens=1`），真的连一下才算数。绿=通、红=不通，悬停看耗时与失败原文（如 `HTTP 503：no usable account for realm cn`）。
- **单模型连续测试**：胶囊里的小圆点，只让这一个模型每 3 秒重测一次，再点停止。多个胶囊可同时各跑各的。
- **切换会话模型**：胶囊右端的 `→`，点了把**当前会话**直接切到该模型，切换成功后该胶囊高亮。
- **连通提示音**：测试由不通变通时响一声，可在 `⚙` 里关闭。
- **`F5`** 刷新页面、**`⟳`** 重启应用（重启需二次确认）。

## 模型从哪来

**全自动，不需要手动导入。** 启动时读取当前 profile 的：

- `cordis.patch.yml` → `llm-pi-ai.providers` 与 `agent-default-model`
- `.credentials.yaml` → 各 provider 的密钥

改了配置或换了 profile，刷新页面即同步。哪些模型显示在胶囊行，可在 `⚙` 里勾选。

## 限制

- 重启按钮**仅 Windows 桌面版**可用；其他平台按钮会自动置灰，不会假装成功。
- 切换模型依赖 DSH 内部接口 `sessionController.selectModel`。版本不支持时点 `→` 会明确提示，不影响连通性测试。
- 插件只拿你的配置去发起测试请求，不上传任何内容到第三方。

## 卸载

设置 → 插件 → 卸载，然后重启 DSH。
